# Drawings to make

Save each drawing in `ui-scrapbook/custom-features/assets/keep-or-toss/`, named exactly as listed.
Two layers, like the Recipe Finder art: `name-color.webp` (the colours) and `name-ink.webp` (the black lines,
which turn cream on the dark page). A single `name.png` or `name.webp` also works.
The build uses yours as soon as the file is there, and a stand-in until then.

**Start here:** the items marked ⭐ are enough to build Level 1 of the game in all three places.
